# Pac-Man

Juego de Pac-Man desarrollado en HTML5, CSS y JavaScript puro (sin dependencias externas).

## Cómo ejecutar

1. Abre el archivo `index.html` en cualquier navegador moderno (Chrome, Firefox, Edge, Safari).
2. Presiona **INICIAR** o una flecha para comenzar.

## Controles

- **Flechas** (↑ ↓ ← →): mover a Pac-Man
- **P**: pausa / continuar
- **R**: reiniciar partida
- **Enter**: reintentar tras perder o ganar

## Características

- Laberinto clásico con puntos y power pellets.
- 4 fantasmas con comportamiento diferenciado (Blinky, Pinky, Inky, Clyde).
- Modo asustado al comer un power pellet (los fantasmas se vuelven azules y pueden ser comidos).
- Sistema de vidas, puntuación y niveles progresivos.
- Un único archivo autocontenido: fácil de enviar y ejecutar.

## Estructura

- `index.html`: todo el juego (HTML + CSS + JavaScript).
